# T02 — program and transport contracts

Status: in progress. Dependencies: T01 integrated as `3e80224`. Branch: `codex/t02-program-transport-contract`.

Deliverable: versioned M1 program, workload, command, reply, event, snapshot, and delta contracts with one checked JSON Schema source, TypeScript projections, and valid/invalid fixtures. This task defines transport and validation behavior but implements no event kernel, policy, persistence store, or UI.

Owner: primary orchestrator, tier A / high responsibility using the session's inherited settings. Owned paths are `content/concepts/program-transport-m1.md`, `packages/contracts/`, `tests/reference/contracts/`, `scripts/validate-contracts.mjs`, this task/evidence record, dependency manifests, and handoff. Simulation behavior remains owned by `sched.m1`; T02 may encode it but cannot change it.

Contract references: specification sections 6–8 and 10; `sched.m1/revision-1`; JSON Schema draft 2020-12; Ajv 8.20.0. Application schema, protocol, model, and engine versions are separate compatibility fields.

Acceptance:

- Commands and replies carry exact protocol, request, and run identity; incompatible protocols are rejected and obsolete-run messages are ignored.
- Ticks, sequence counters, durations, and other 64-bit integers use canonical decimal strings without JSON precision loss.
- Programs provide stable source-block IDs and only the M1 compute, I/O wait, yield, bounded repeat, and end operations; supplied code is never evaluated.
- Structural and semantic validation reject malformed references, duplicate IDs, invalid ranges/defaults, excessive size/depth/block count, unknown properties, unsafe identifiers, and unsupported versions.
- Create/start/pause/advance/inspect/checkpoint/cancel/supported-intervention commands and acknowledgment/progress/state/completion/cancellation/error replies are discriminated.
- Events have stable IDs, ticks, entity/source/causal links, and kind-specific payloads. Snapshots have sequence numbers; deltas identify their exact base and target sequences. A sequence gap requires a full resynchronization request.
- Valid and invalid fixtures are checked against one shared schema. TypeScript projections compile against strict mode. Large-integer and negative-control checks demonstrate that validators reject precision-unsafe or corrupted inputs.
- A separate tier-A review must approve the contract before T03.

Verification commands:

```text
npm run contracts:check
npm run typecheck
npm run format:check
git diff --check
```

Reviewer: independent tier A / high. Escalate if T02 would change a T01 scheduling outcome, if one command/reply can match multiple variants, if exact integer transport is lost, or if T03 would need to invent lifecycle/error/delta behavior.

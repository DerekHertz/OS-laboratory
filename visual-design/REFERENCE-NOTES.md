# Visual direction studies

Status: alternatives for discussion, not an approved frontend design. Generated using the built-in image generation tool.

## Directions

- A: Precision Lab — graphite hardware, cyan activity, ivory robot. Strong technical instrument aesthetic.
- B: Warm Workshop — parchment panels, teal hardware, ochre technician. Warm illustrated laboratory.
- C: Pixel Circuit — midnight panels, mint activity, service bot. Pixel-art environment with modern readable UI.

All three share side-on traversal, CPU bays, RAM, stations, a thread inspector and a bottom timeline. Character studies and palette swatches are included in each image. PNGs are style/layout references, not assets to slice into production UI.

## Frontend interpretation

The existing product specification remains authoritative. Render labels and controls as live UI, not baked image text. Use independent world art/sprites. Derive activity from engine state. Do not implement invented image details such as actual register values, C execution, DDR4 characteristics, or disk semantics in the initial abstract-I/O model.

Review findings: generated queue counts and timelines are illustrative and not internally verified. A contains an invalid-looking “Thread 07 of 3” counter. B's “Waiting On” panel introduces another thread without a clear selection boundary. C mixes state colors with thread colors and labels I/O wait separately from blocked. Replace these with one consistent state legend: running, runnable, blocked, terminated; blocked reason is additional metadata. Exact hex values below come from prompts, not sampled generated pixels. Palette contrast must be checked during implementation. Character front poses are approximate, not production turnarounds or animation spritesheets.

Recommended next step: choose world style and character independently, then generate one refined reference showing overview, selected-thread inspection and block-editor states. Produce a precise token sheet and actual sprite turnaround only after direction selection.
